================================================================================
INTEGRATION REQUIREMENTS
================================================================================

SERVER-SIDE
- Fire RemoteEvents from your game logic loop
- Example: updateFuelEvent:FireClient(player, currentFuel, maxFuel)
- Update leaderboard periodically (once per second recommended)
- Send death event when player dies with brainrot data

CLIENT-SIDE (AUTOMATIC)
- HUDClient.client.lua handles all setup
- No manual initialization needed
- Place in src/client/ directory
- Will auto-require GUI modules from src/gui/

DEPENDENCIES
- GameConfig: Requires shared.GameConfig (already exists)
- HelicopterData: Requires shared.HelicopterData (already exists)
- TweenService: Roblox built-in
- RunService: Roblox built-in
- UserInputService: Roblox built-in

================================================================================
PERFORMANCE NOTES
================================================================================

Memory Usage
- MainHUD GUI: ~50KB
- Leaderboard GUI: ~40KB
- DeathScreen GUI: ~35KB
- Runtime state tracking: <10KB

Network Usage
- Fuel updates: Continuous (recommend batching)
- Leaderboard: Once per second (5-10KB per broadcast)
- Events: Only fired when needed
- Total: Minimal impact on bandwidth

Optimization Tips
1. Batch fuel updates to 10 times per second max
2. Update leaderboard every 1 second (not every frame)
3. Use :Destroy() on notification frames automatically (already implemented)
4. Consider disabling leaderboard for mobile players if needed
