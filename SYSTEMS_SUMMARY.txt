INTEGRATION POINTS:
================================================================================

SERVER FLOW:
  BrainrotSystem.OnBrainrotDeath()
    ↓
  Finds killing player within 100 studs
    ↓
  Calls BrainrotCollector.TryCollect()
    ↓
  Random chance check per tier
    ↓
  Saves to DataStore if collected
    ↓
  Fires BrainrotCollected event to client

CLIENT FLOW (COLLECTION):
  Player presses C
    ↓
  CollectionGUI.ToggleCollection()
    ↓
  Calls GetBrainrotCollection RemoteFunction
    ↓
  Server returns tier data with collection status
    ↓
  Populates grid with cards
    ↓
  Shows "X/8 Collected" progress

SERVER FLOW (WATER):
  Player Y position < -10
    ↓
  WaterSystem detects fall every 0.2 seconds
    ↓
  Fires WaterSplash event
    ↓
  Waits 3 seconds
    ↓
  Restores player health & position
    ↓
  Restarts plane with saved config
    ↓
  Refills fuel to maximum

CLIENT FLOW (WATER):
  Receives WaterSplash event
    ↓
  Creates 20 particle droplets
    ↓
  Plays screen blue flash (0.5s)
    ↓
  Applies camera shake (0.4s)
    ↓
  Plays splash sound (0.5s volume)
    ↓
  Shows "You fell into water!" notification
    ↓
  All effects fade naturally

DATASTORE STRUCTURE:
================================================================================

Store: "BrainrotCollections_v1"
Key: "collection_[userId]"

Format:
{
  "Common": {"collected": true, "timestamp": 1234567890},
  "Uncommon": {"collected": true, "timestamp": 1234567891},
  "Rare": {"collected": false},
  "Epic": {"collected": false},
  "Mythic": {"collected": false},
  "Secret": {"collected": false},
  "Celestial": {"collected": false},
  "OP": {"collected": false}
}

Size per player: ~300 bytes
Retention: Permanent until manually deleted

================================================================================
REMOTE EVENTS & FUNCTIONS:
================================================================================

BrainrotCollected
  Type: RemoteEvent
  Direction: Server → Client
  Parameters: tierName (string), displayName (string)
  Usage: Notify player of successful collection

GetBrainrotCollection
  Type: RemoteFunction
  Direction: Client ← → Server
  Returns: {tiers, totalCollected, totalTiers}
  Usage: Load collection data for UI

WaterSplash
  Type: RemoteEvent
  Direction: Server → Client
  Parameters: None
  Usage: Trigger all splash effects

PlaneRestart
  Type: RemoteEvent
  Direction: Server → Client
  Parameters: message (string)
  Usage: Show restart notification
