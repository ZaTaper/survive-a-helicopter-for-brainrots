REMOTE EVENTS TO FIRE FROM SERVER
(All auto-created in ReplicatedStorage.HUDEvents)

UpdateFuel(currentFuel, maxFuel)
  └─ Fires every frame during flight

UpdateSpeed(speed)
  └─ Fires when engine count changes

UpdateInventory(engines, canisters, currentFuel)
  └─ Fires when player picks up items

UpdateKillCount(killCount)
  └─ Fires when brainrot is eliminated

UpdateWave(waveNumber)
  └─ Fires when wave counter increments

UpdatePhase(phase, duration)
  └─ Fires at phase transitions (LOBBY, BUILD, SURVIVE, ROUNDEND)

UpdateLeaderboard(leaderboardDataTable)
  └─ Fires once per second (broadcast to all players)

PlayerDied(brainrotName, brainrotTier, tierColor)
  └─ Fires when player dies

PickupNotification(itemType, quantity)
  └─ Fires when player picks up engine or canister

SERVER CODE TEMPLATE

-- Initialize in your server script:
local HUDEvents = ReplicatedStorage:WaitForChild("HUDEvents")

-- Update fuel (in flight loop):
HUDEvents:WaitForChild("UpdateFuel"):FireClient(player, currentFuel, maxFuel)

-- Send death:
HUDEvents:WaitForChild("PlayerDied"):FireClient(player, "Brainrot Name", "TIER", Color3.fromRGB(r,g,b))

-- Broadcast leaderboard (every 1 second):
local data = {
    ["Player1"] = {wavesSurvived = 5, kills = 12, speed = 50},
    ["Player2"] = {wavesSurvived = 3, kills = 8, speed = 35},
}
for _, p in ipairs(Players:GetPlayers()) do
    HUDEvents:WaitForChild("UpdateLeaderboard"):FireClient(p, data)
end

TROUBLESHOOTING

Problem: Fuel bar not animating
→ Check if UpdateFuel event is firing from server

Problem: Leaderboard won't open
→ Check Tab key in UserInputService, verify Leaderboard:Init() was called

Problem: Death screen doesn't appear
→ Ensure PlayerDied event fires with correct parameters

Problem: Phase timer stuck
→ Verify UpdatePhase fires with duration parameter

Problem: Kill counter not updating
→ Check UpdateKillCount event from server

Problem: Colors look different
→ Verify RGB values match GameConfig.BrainrotTiers
