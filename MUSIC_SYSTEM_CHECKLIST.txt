PHASE 9: TROUBLESHOOTING (If Issues Occur)
================================================================================

NO MUSIC PLAYING:
[ ] Check that sound IDs are NOT "rbxassetid://0" (placeholder)
[ ] Verify Asset IDs from Roblox Creator Dashboard are correct
[ ] Check Output console for error messages
[ ] Ensure audio files were successfully uploaded to Roblox
[ ] Try waiting 1-2 minutes for Roblox to process files
[ ] Try a different audio file to rule out format issues

MUSIC CUTS OFF:
[ ] Verify looped = true is set for all background music tracks
[ ] Check that Death sound has looped = false
[ ] Look for errors in Output console
[ ] Ensure sound object Parent is still set correctly

SETTINGS UI NOT SHOWING:
[ ] Check that MusicSettings.lua is in src/gui/ folder
[ ] Verify MusicClient.client.lua can find the module
[ ] Look for errors in Output console
[ ] Try restarting the game

CROSSFADE SOUNDS WEIRD:
[ ] Increase CROSSFADE_DURATION in MusicData.lua
[ ] Ensure track volumes are balanced
[ ] Check that audio files themselves aren't distorted

WRONG MUSIC PLAYING:
[ ] Verify phase detection in Output console
[ ] Check that track keys match MusicData.lua exactly
[ ] Look for phase change messages in console

VOLUME SLIDER NOT WORKING:
[ ] Check browser/studio input handling
[ ] Verify slider UI elements are visible
[ ] Look for errors in Output console
[ ] Try clicking slider at different positions
